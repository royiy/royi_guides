# מדריך 1: מבוא, התקנה והגדרות בסיסיות של Windows Server 🖥️

## מבוא
Windows Server היא מערכת ההפעלה של Microsoft המיועדת לסביבות ארגוניות (Enterprise). בניגוד למערכות הפעלה למשתמשי קצה (כמו Windows 10/11), גרסת השרת מותאמת לספק שירותי רשת (Roles & Features) למספר רב של משתמשים במקביל, כגון ניהול זהויות, שרתי קבצים, שירותי וירטואליזציה ועוד.

בעת ההתקנה, ניתן לבחור בשתי תצורות עיקריות:
1. **Desktop Experience (GUI):** עם ממשק משתמש מלא, מתאים למנהלים מתחילים או לאפליקציות הדורשות ממשק גרפי.
2. **Server Core:** ללא ממשק גרפי (שורת פקודה בלבד). יתרונותיו: צריכת משאבים מינימלית, דורש פחות עדכונים, ומספק "שטח תקיפה" (Attack Surface) מצומצם בהרבה, מה שהופך אותו למאובטח יותר.

## פקודות ומושגים - בסיסי ומתקדם
*   **Server Manager:** הממשק הגרפי המרכזי שדרכו מנהלים שרתים מרובים ומוסיפים Roles ו-Features.
*   **sconfig:** כלי שורת פקודה המובנה ב-Server Core המאפשר הגדרות רשת, שם שרת, דומיין, ועדכונים בקלות דרך תפריט טקסטואלי.
*   **Sysprep:** כלי חובה להכנת מערכת ההפעלה ליצירת Image. הוא מוחק נתונים ייחודיים לשרת כמו ה-SID (Security Identifier) כך שניתן לשכפל אותו לשרתים חדשים ללא התנגשויות.

### פקודות PowerShell שימושיות לקינפוג ראשוני:
```powershell
# שינוי שם השרת והפעלה מחדש
Rename-Computer -NewName "SRV-DC-01" -Restart

# הגדרת כתובת IP סטטית (חשוב מאוד לשרתים)
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.10 -PrefixLength 24 -DefaultGateway 192.168.1.1

# הגדרת שרתי DNS
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.1.10, 8.8.8.8

# התקנת רכיב שרת (לדוגמה, שרת Web)
Install-WindowsFeature -Name Web-Server -IncludeManagementTools
```

## דוגמאות מפורטות
**תרחיש:** הקמת שרת חדש ברשת הארגונית.
1. התקינו גרסת **Server Core** כדי לשמור על רמת אבטחה וביצועים גבוהים.
2. עם עליית השרת, הקלידו `sconfig` כדי לפתוח את תפריט הניהול.
3. בחרו באפשרות של הגדרות רשת וקבעו כתובת IP סטטית. שרתים (ובמיוחד Domain Controllers או שרתי DNS) חייבים כתובת קבועה כדי ששאר המחשבים ברשת ידעו כיצד לגשת אליהם.
4. שנו את שם השרת לשם בעל משמעות לפי קונבנציית הארגון (למשל `HR-FILE-SRV01`).
5. לאחר הפעלה מחדש, צרפו את השרת לדומיין בעזרת `Add-Computer -DomainName "corp.local"`.

## טיפים וטריקים 💡
*   **סדר פעולות נכון:** לעולם אל תצרפו שרת לדומיין לפני שווידאתם שכתובת ה-IP שלו מוגדרת נכון, ושה-DNS שלו מצביע ל-Domain Controller של הארגון.
*   **Windows Admin Center (WAC):** כלי ניהול מבוסס Web חינמי ממיקרוסופט. התקינו אותו על שרת ניהול ודרכו תוכלו לנהל עשרות שרתי Server Core בממשק גרפי מודרני מתוך הדפדפן, ללא צורך ב-RDP לכל שרת.
*   **Best Practice:** תמיד השאירו משתמש Local Administrator עם סיסמה חזקה למקרי חירום (Break-glass account) למקרה שהדומיין קורס ואין אפשרות להתחבר עם משתמש רשת.

## שאלות ראיון עבודה 🎯
1. **שאלה:** מה ההבדל בין Roles ל-Features ב-Windows Server?
   *תשובה:* Role הוא התפקיד המרכזי של השרת (לדוגמה: שרת קבצים, שרת DNS, בקר דומיין). Feature הוא תוספת או כלי עזר התומך ב-Roles או בשרת עצמו (לדוגמה: Failover Clustering, תכונות גיבוי, BitLocker).
2. **שאלה:** מדוע משתמשים ב-Sysprep, ומה עלול לקרות אם לא נשתמש בו לפני יצירת קלון (Clone) לשרת?
   *תשובה:* Sysprep מכין את המערכת להפצה. אם נשכפל שרת ללא Sysprep, שני השרתים יקבלו את אותו SID (Security Identifier). ברשת Active Directory הדבר יגרום להתנגשויות חמורות, בעיות הרשאות וקריסת שירותים, מכיוון שה-AD מזהה מחשבים לפי ה-SID ולא לפי השם.
3. **שאלה:** מה היתרון של Server Core?
   *תשובה:* אבטחה (שטח תקיפה קטן), פחות תקלות תוכנה, התקנה קלה, דורש פחות הפעלות מחדש לאחר עדכונים, וחיסכון משמעותי במשאבי RAM ו-CPU.
