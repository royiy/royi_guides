## מבוא
מעבר לפקודות הבסיסיות, ניהול קבצים בלינוקס כולל דחיסה, קישורים (Links), ניהול חיפוש מתקדם, וכלים לעריכת טקסט מהשורת פקודה. מדריך זה מרחיב בנושאים אלו.

---

## 1. דחיסה וארכיון

### tar - הכלי הקלאסי לארכיון
```bash
# יצירת ארכיון tar עם דחיסת gzip
tar -czvf archive.tar.gz /path/to/directory

# חילוץ ארכיון
tar -xzvf archive.tar.gz

# חילוץ לתיקייה ספציפית
tar -xzvf archive.tar.gz -C /destination/path

# הצגת תוכן ארכיון בלי לחלץ
tar -tvf archive.tar.gz

# דחיסה עם bzip2 (דחיסה טובה יותר, איטית יותר)
tar -cjvf archive.tar.bz2 /path
```

הסבר הדגלים: `c`=create, `x`=extract, `z`=gzip, `j`=bzip2, `v`=verbose, `f`=filename

### zip/unzip
```bash
zip -r archive.zip /path/to/directory
unzip archive.zip
unzip -l archive.zip   # הצגת תוכן בלי חילוץ
```

### gzip
```bash
gzip file.txt          # יוצר file.txt.gz ומוחק את המקור
gunzip file.txt.gz     # חילוץ חזרה
zcat file.txt.gz       # צפייה בתוכן בלי חילוץ
```

## 2. קישורים (Links) - Symbolic vs Hard

```bash
# קישור סימבולי (כמו קיצור דרך בווינדוס) - יכול להצביע על תיקיות ולעבור בין מערכות קבצים
ln -s /path/to/original /path/to/symlink

# קישור קשיח (Hard Link) - מצביע ישירות ל-inode, לא יכול להצביע על תיקייה
ln /path/to/original /path/to/hardlink

# בדיקת קישורים
ls -li
```

**ההבדל המרכזי:**
- **Symbolic Link**: קובץ נפרד שמצביע לנתיב. אם מוחקים את המקור - הקישור נשבר.
- **Hard Link**: שם נוסף לאותו inode בדיסק. הקובץ נמחק בפועל רק כשכל ה-Hard Links נמחקים.

## 3. עריכת טקסט מהשורת פקודה

### sed - Stream Editor
```bash
# החלפת מחרוזת בקובץ (הצגה בלבד, לא שומר)
sed 's/old/new/g' file.txt

# החלפה ושמירה בקובץ המקורי
sed -i 's/old/new/g' file.txt

# מחיקת שורות ריקות
sed '/^$/d' file.txt

# הדפסת שורות 5 עד 10 בלבד
sed -n '5,10p' file.txt
```

### awk - עיבוד נתונים בעמודות
```bash
# הדפסת העמודה הראשונה מקובץ מופרד ברווחים
awk '{print $1}' file.txt

# עבודה עם קובץ CSV (מופרד בפסיקים)
awk -F',' '{print $2}' data.csv

# סיכום עמודה מספרית
awk '{sum += $3} END {print sum}' data.txt

# הדפסת שורות שעומדות בתנאי
awk '$3 > 100 {print $0}' data.txt
```

### cut, sort, uniq
```bash
# חיתוך עמודה מסוימת
cut -d',' -f2 data.csv

# מיון קובץ
sort file.txt

# מיון הפוך
sort -r file.txt

# מיון מספרי
sort -n numbers.txt

# הסרת כפילויות (חייב sort לפני)
sort file.txt | uniq

# ספירת מופעים ייחודיים
sort file.txt | uniq -c
```

## 4. שיתוף וסנכרון קבצים

### rsync - כלי סנכרון עוצמתי
```bash
# סנכרון תיקייה מקומית
rsync -avh /source/ /destination/

# סנכרון לשרת מרוחק דרך SSH
rsync -avz -e ssh /local/dir/ user@remote:/remote/dir/

# סנכרון עם מחיקת קבצים שלא קיימים במקור
rsync -avz --delete /source/ /destination/

# הצגת מה ישתנה בלי לבצע (dry run)
rsync -avzn /source/ /destination/
```

### scp - העתקת קבצים בין שרתים
```bash
# העתקה משרת מרוחק למחשב מקומי
scp user@remote:/path/file.txt /local/path/

# העתקה מהמחשב המקומי לשרת מרוחק
scp /local/file.txt user@remote:/remote/path/

# העתקת תיקייה שלמה
scp -r /local/dir user@remote:/remote/dir
```

## 5. הרשאות דיסק וקצאת שטח

```bash
# בדיקת שימוש בדיסק לפי partition
df -h

# בדיקת שימוש בתיקייה ותתי-תיקיות (5 הכי גדולות)
du -h --max-depth=1 /var | sort -rh | head -5

# מציאת הקבצים הכבדים ביותר במערכת
find / -type f -size +500M 2>/dev/null
```

## טיפים וטריקים 🔥

1. **`ncdu`** - כלי ויזואלי אינטראקטיבי לניתוח שימוש בדיסק, הרבה יותר נוח מ-`du`.
2. השתמשו ב-`rsync` במקום `cp` לגיבויים - הוא מעתיק רק מה שהשתנה.
3. **`xargs`** - שילוב מעולה עם `find`: `find . -name "*.tmp" | xargs rm`
4. תמיד השתמשו ב-`--dry-run` או `-n` בפקודות מסוכנות לפני הרצה אמיתית.
5. גבו קבצי קונפיגורציה לפני עריכה: `cp file.conf file.conf.bak`

## שאלות ראיון עבודה נפוצות

1. **מה ההבדל בין Hard Link ל-Symbolic Link?**
   ראו הסבר בסעיף 2 למעלה - ההבדל המרכזי הוא ש-Hard Link מצביע ישירות ל-inode בעוד Symbolic Link הוא קובץ נפרד עם נתיב.

2. **איך תדחסו תיקייה שלמה עם tar?**
   `tar -czvf archive.tar.gz /path/to/dir`

3. **מה ההבדל בין rsync ל-scp?**
   `rsync` מעביר רק שינויים (delta) ותומך בהמשך העברות שנקטעו, בעוד `scp` מעתיק תמיד את כל הקובץ מחדש.

4. **איך תמצאו ותמחקו את כל הקבצים בעלי סיומת .log שגדולים מ-1GB?**
   ```bash
   find / -name "*.log" -size +1G -exec rm {} \;
   ```

5. **מה זה inode?**
   מבנה נתונים במערכת הקבצים שמאחסן metadata על קובץ (הרשאות, בעלים, גודל, מיקום הבלוקים בדיסק) - אך לא את שם הקובץ עצמו.
