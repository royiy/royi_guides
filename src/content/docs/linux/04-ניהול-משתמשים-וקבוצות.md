# מדריך 4: ניהול משתמשים וקבוצות

## מבוא
ניהול משתמשים הוא בסיס לאבטחת מערכת לינוקס. מדריך זה מכסה יצירה, עריכה ומחיקה של משתמשים וקבוצות, וכן ניהול הרשאות sudo.

---

## 1. קבצי המערכת המרכזיים

| קובץ | תוכן |
|---|---|
| `/etc/passwd` | רשימת כל המשתמשים במערכת (שם, UID, GID, home, shell) |
| `/etc/shadow` | סיסמאות מוצפנות (נגיש רק ל-root) |
| `/etc/group` | רשימת כל הקבוצות |
| `/etc/sudoers` | הגדרות הרשאות sudo |

```bash
# צפייה במבנה passwd
cat /etc/passwd
# פורמט: username:x:UID:GID:comment:home_dir:shell

# דוגמה לשורה:
# john:x:1001:1001:John Doe:/home/john:/bin/bash
```

---

## 2. יצירה וניהול משתמשים

```bash
# יצירת משתמש חדש (עם תיקיית home)
sudo useradd -m john

# יצירת משתמש עם shell ספציפי ותיקיית home מותאמת
sudo useradd -m -d /home/john -s /bin/bash john

# הגדרת סיסמה למשתמש
sudo passwd john

# יצירה בשיטה אינטראקטיבית (adduser - נוח יותר, זמין בדביאן/אובונטו)
sudo adduser john

# עריכת פרטי משתמש קיים
sudo usermod -aG sudo john    # הוספה לקבוצת sudo
sudo usermod -s /bin/zsh john # שינוי shell

# נעילת/פתיחת חשבון
sudo usermod -L john   # נעילה
sudo usermod -U john   # פתיחה

# מחיקת משתמש (בלי תיקיית home)
sudo userdel john

# מחיקת משתמש כולל תיקיית home וכל הקבצים שלו
sudo userdel -r john
```

⚠️ **חשוב**: הדגל `-aG` הוא קריטי - `-G` בלבד **מחליף** את כל הקבוצות המשניות של המשתמש, בעוד `-aG` **מוסיף** קבוצה בלי למחוק אחרות.

---

## 3. ניהול קבוצות

```bash
# יצירת קבוצה חדשה
sudo groupadd developers

# הוספת משתמש קיים לקבוצה
sudo usermod -aG developers john

# הצגת הקבוצות של משתמש
groups john
id john

# מחיקת קבוצה
sudo groupdel developers

# שינוי הקבוצה הראשית (Primary Group) של משתמש
sudo usermod -g developers john
```

## 4. sudo וניהול הרשאות מנהל

```bash
# עריכה בטוחה של קובץ sudoers (עם בדיקת syntax)
sudo visudo

# מתן הרשאות sudo מלאות למשתמש (בקובץ sudoers)
john ALL=(ALL:ALL) ALL

# מתן הרשאה להריץ פקודה ספציפית בלבד ללא סיסמה
john ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart nginx

# הרצת פקודה כמשתמש אחר
sudo -u www-data whoami

# מעבר למשתמש root לחלוטין
sudo -i
# או
sudo su -
```

---

## 5. ניהול סיסמאות ומדיניות אבטחה

```bash
# שינוי סיסמה אישית
passwd

# הגדרת תפוגת סיסמה (ימים) למשתמש
sudo chage -M 90 john

# הצגת מידע על תפוגת הסיסמה
sudo chage -l john

# חסימת התחברות SSH למשתמש ספציפי - עריכת /etc/ssh/sshd_config
# DenyUsers john
```

---

## 6. מעבר בין משתמשים

```bash
# מעבר למשתמש אחר (עם סביבת ה-shell שלו)
su - john

# מעבר זמני להרצת פקודה בודדת
su -c "ls -la" john

# בדיקה מי המשתמש הנוכחי
whoami

# בדיקת כל המשתמשים המחוברים כרגע
who
w
```

## טיפים וטריקים 🔥

1. השתמשו תמיד ב-`visudo` לעריכת sudoers - הוא בודק syntax לפני שמירה ומונע נעילה מלאה מהמערכת.
2. הימנעו מלתת הרשאות `sudo ALL=(ALL) NOPASSWD: ALL` - זה מבטל את כל היתרון האבטחתי של sudo.
3. `getent passwd` מציג משתמשים גם ממקורות מרוחקים (LDAP וכו') ולא רק מ-`/etc/passwd`.
4. תמיד בדקו `last` כדי לראות היסטוריית התחברויות למערכת - מועיל לזיהוי פעילות חשודה.
5. שמרו על עיקרון "הרשאה מינימלית" (Least Privilege) - תנו למשתמשים רק את מה שהם צריכים.

## שאלות ראיון עבודה נפוצות

1. **מה ההבדל בין `su` ל-`sudo`?**
   `su` מחליף את כל הסשן למשתמש אחר (דורש את הסיסמה של המשתמש היעד), בעוד `sudo` מריץ פקודה בודדת בהרשאות מוגברות (דורש את הסיסמה של המשתמש הנוכחי, בהתאם להגדרות sudoers).

2. **איך תוסיפו משתמש לקבוצה נוספת בלי להסיר אותו מהקבוצות הקיימות?**
   `usermod -aG groupname username` - הדגל `-a` (append) קריטי כאן.

3. **מה נמצא בקובץ `/etc/shadow` ולמה הוא לא ב-`/etc/passwd`?**
   סיסמאות מוצפנות (hash). הן הופרדו מ-`/etc/passwd` (שקריא לכולם) כי `/etc/passwd` צריך להיות נגיש לכל תהליך לצורך resolve של UID לשם, בעוד הסיסמאות דורשות הגנה מוגברת ונגישות רק ל-root.

4. **איך בודקים לאילו קבוצות משתמש שייך?**
   `groups username` או `id username`

5. **מה ההבדל בין UID 0 למשתמשים אחרים?**
   UID 0 הוא תמיד root - הרשאות מלאות במערכת, ללא הגבלות.
