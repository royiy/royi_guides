## מבוא
לינוקס היא מערכת הפעלה מבוססת Unix, הנשלטת בעיקרה דרך שורת פקודה (Shell/Terminal). מדריך זה מכסה את הפקודות הבסיסיות ביותר שכל מנהל מערכת, מפתח או משתמש לינוקס חייב להכיר.

---

## 1. ניווט בסיסי במערכת הקבצים

| פקודה | תיאור | דוגמה |
|---|---|---|
| `pwd` | מציגה את הנתיב הנוכחי (Print Working Directory) | `pwd` |
| `ls` | מציגה תוכן תיקייה | `ls -la` |
| `cd` | מעבר בין תיקיות | `cd /var/log` |
| `tree` | מציגה מבנה עץ של תיקיות | `tree -L 2` |

### דוגמאות מפורטות
```bash
# הצגת כל הקבצים כולל נסתרים, עם פרטים מלאים
ls -la

# הצגת גודל קבצים בפורמט קריא לבני אדם
ls -lh

# מעבר לתיקיית הבית
cd ~

# מעבר לתיקייה הקודמת בה היינו
cd -

# מעבר לתיקיית האב
cd ..
```

## 2. עבודה עם קבצים ותיקיות

```bash
# יצירת תיקייה (כולל תיקיות ביניים)
mkdir -p /home/user/projects/linux

# יצירת קובץ ריק
touch file.txt

# העתקת קובץ
cp source.txt destination.txt

# העתקת תיקייה כולל תוכן (רקורסיבית)
cp -r dir1/ dir2/

# העברה/שינוי שם
mv oldname.txt newname.txt

# מחיקת קובץ
rm file.txt

# מחיקת תיקייה עם כל תוכנה (זהירות!)
rm -rf directory/

# מחיקה עם בקשת אישור
rm -i file.txt
```

⚠️ **טיפ אבטחה**: לעולם אל תריצו `rm -rf /` או `rm -rf *` בלי לוודא בדיוק היכן אתם נמצאים. מומלץ להשתמש ב-`rm -i` בסביבות רגישות.

## 3. צפייה בתוכן קבצים

```bash
# הצגת כל תוכן הקובץ
cat file.txt

# הצגה עמוד-עמוד
less file.txt

# הצגת 10 השורות הראשונות
head -n 10 file.txt

# הצגת 10 השורות האחרונות
tail -n 10 file.txt

# מעקב חי אחרי קובץ log (שימושי מאוד לדיבוג)
tail -f /var/log/syslog

# ספירת שורות, מילים ותווים
wc -l file.txt
```

## 4. חיפוש קבצים ותוכן

```bash
# חיפוש קבצים לפי שם
find /home -name "*.txt"

# חיפוש קבצים ששונו ב-7 הימים האחרונים
find / -mtime -7 -type f

# חיפוש טקסט בתוך קבצים
grep "error" /var/log/syslog

# חיפוש רקורסיבי בכל תת-התיקיות
grep -r "TODO" /home/user/project/

# חיפוש עם התעלמות מרישיות (case-insensitive)
grep -i "warning" logfile.txt

# שילוב find עם grep
find . -name "*.log" -exec grep -l "fail" {} \;

# locate - חיפוש מהיר מבוסס אינדקס (דורש updatedb)
locate nginx.conf
```

## 5. הרשאות ובעלות (סקירה ראשונית)
מדריך מלא בנושא נמצא בקובץ 03, אך פקודות בסיסיות:

```bash
# שינוי הרשאות
chmod 755 script.sh

# שינוי בעלים
chown user:group file.txt

# הפיכת קובץ להרצה
chmod +x script.sh
```

## 6. מידע על המערכת

```bash
# גרסת קרנל
uname -a

# מידע על הפצת הלינוקס
cat /etc/os-release

# שימוש בזיכרון
free -h

# שימוש בדיסק
df -h

# גודל תיקייה ספציפי
du -sh /var/log

# זמן פעולה (Uptime)
uptime

# מידע על מעבד
lscpu
```

## 7. Pipes וRedirection (צנרת והפניה)

```bash
# צנרת - העברת פלט של פקודה כקלט לפקודה הבאה
ls -la | grep ".txt"

# הפניית פלט לקובץ (דריסה)
echo "Hello" > output.txt

# הפניית פלט לקובץ (הוספה בסוף)
echo "World" >> output.txt

# הפניית קלט מקובץ
sort < names.txt

# שילוב פקודות מרובות
cat access.log | grep "404" | wc -l
```

## 8. פקודות שימושיות נוספות

```bash
# היסטוריית פקודות
history

# הרצת פקודה מההיסטוריה לפי מספר
!245

# ניקוי המסך
clear

# מי אני
whoami

# מידע על משתמש
id

# man page - התיעוד המובנה של כל פקודה
man ls

# עזרה מהירה
ls --help
```

## טיפים וטריקים 🔥

1. **שימוש ב-Tab להשלמה אוטומטית** - חוסך המון זמן הקלדה.
2. **Ctrl+R** - חיפוש רברסיבי בהיסטוריית הפקודות.
3. **Ctrl+C** - עצירת פקודה רצה. **Ctrl+Z** - השהיה (העברה לרקע עם `bg`).
4. **alias** - יצירת קיצורי דרך: `alias ll='ls -la'` (הוסיפו ל-`~/.bashrc`).
5. **`!!`** - הרצה חוזרת של הפקודה האחרונה (שימושי עם `sudo !!`).
6. השתמשו ב-`man` או `tldr` (כלי חיצוני נהדר) כדי ללמוד פקודות חדשות במהירות.

## שאלות ראיון עבודה נפוצות

1. **מה ההבדל בין `>` ל-`>>`?**
   `>` דורס את הקובץ, `>>` מוסיף לסופו.

2. **איך תמצאו את כל הקבצים הגדולים מ-100MB בתיקייה מסוימת?**
   ```bash
   find /path -type f -size +100M
   ```

3. **מה ההבדל בין `cat`, `less` ו-`more`?**
   `cat` מציג הכל בבת אחת, `more`/`less` מאפשרים גלילה - `less` יעיל יותר בקבצים גדולים ותומך בגלילה לאחור.

4. **איך בודקים כמה מקום פנוי יש בדיסק?**
   `df -h`

5. **מה עושה `grep -v`?**
   מציג את כל השורות ש**לא** מכילות את התבנית המבוקשת (Invert Match).
