# מדריך 3: ניהול הרשאות ובעלות בלינוקס

## מבוא
מערכת ההרשאות בלינוקס היא אחד הנושאים החשובים ביותר להבנה עמוקה - הן לצורך אבטחה והן כי היא נשאלת כמעט בכל ראיון עבודה לתפקידי DevOps/SysAdmin.

---

## 1. מבנה הרשאות בסיסי

כל קובץ בלינוקס מציג הרשאות בפורמט כזה כשמריצים `ls -l`:

```
-rwxr-xr-- 1 user group 4096 Jan 1 12:00 file.sh
```

פירוק המחרוזת `rwxr-xr--`:

| קבוצה | תווים | משמעות |
|---|---|---|
| סוג קובץ | `-` | קובץ רגיל (`d`=תיקייה, `l`=קישור סימבולי) |
| בעלים (Owner/User) | `rwx` | קריאה, כתיבה, הרצה |
| קבוצה (Group) | `r-x` | קריאה, הרצה (ללא כתיבה) |
| אחרים (Others) | `r--` | קריאה בלבד |

- `r` (Read) = 4
- `w` (Write) = 2
- `x` (Execute) = 1

## 2. chmod - שינוי הרשאות

### שיטה מספרית (Octal)
```bash
# 755 = rwxr-xr-x
chmod 755 script.sh

# 644 = rw-r--r-- (טיפוסי לקבצים רגילים)
chmod 644 document.txt

# 700 = rwx------ (רק הבעלים יכול לגשת - שימושי למפתחות SSH)
chmod 700 ~/.ssh/id_rsa

# 777 = הרשאה מלאה לכולם (מסוכן! להימנע!)
chmod 777 file.txt
```

טבלת חישוב מהירה:
| מספר | הרשאה |
|---|---|
| 7 | rwx |
| 6 | rw- |
| 5 | r-x |
| 4 | r-- |
| 0 | --- |

### שיטה סימבולית
```bash
# הוספת הרשאת הרצה לבעלים
chmod u+x script.sh

# הסרת הרשאת כתיבה מהקבוצה
chmod g-w file.txt

# הרשאת קריאה לכולם
chmod a+r file.txt

# מספר שינויים בבת אחת
chmod u+x,g-w,o=r file.txt

# הפעלה רקורסיבית על תיקייה
chmod -R 755 /var/www/html
```

`u`=user, `g`=group, `o`=others, `a`=all

---

## 3. chown - שינוי בעלות

```bash
# שינוי בעלים בלבד
chown newuser file.txt

# שינוי בעלים וקבוצה יחד
chown newuser:newgroup file.txt

# שינוי קבוצה בלבד (אפשר גם עם chgrp)
chown :newgroup file.txt
chgrp newgroup file.txt

# שינוי רקורסיבי על תיקייה שלמה
chown -R www-data:www-data /var/www/html
```

## 4. הרשאות מיוחדות: SUID, SGID, Sticky Bit

### SUID (Set User ID) - ספרה 4
כאשר קובץ הרצה מסומן ב-SUID, הוא רץ בהרשאות הבעלים שלו ולא בהרשאות המשתמש שהריץ אותו.
```bash
chmod 4755 /usr/bin/passwd
# מוצג כ: -rwsr-xr-x
```
דוגמה קלאסית: פקודת `passwd` צריכה לכתוב ל-`/etc/shadow` שרק root יכול לגשת אליו, אז יש לה SUID על root.

### SGID (Set Group ID) - ספרה 2
על תיקייה - כל קובץ חדש שנוצר בתוכה יורש את קבוצת התיקייה.
```bash
chmod 2775 /shared/project
# מוצג כ: drwxrwsr-x
```

### Sticky Bit - ספרה 1
על תיקייה - רק הבעלים של קובץ (או root) יכול למחוק אותו, גם אם לאחרים יש הרשאת כתיבה. משמש ב-`/tmp`.
```bash
chmod 1777 /tmp
# מוצג כ: drwxrwxrwt
```

## 5. umask - הרשאות ברירת מחדל

`umask` קובע אילו הרשאות **יורדות** אוטומטית מקבצים ותיקיות חדשים.

```bash
# בדיקת umask נוכחי
umask

# ברירת מחדל טיפוסית: 022
# משמעות: קבצים חדשים = 666-022 = 644, תיקיות חדשות = 777-022 = 755

# שינוי umask לסשן הנוכחי
umask 027

# הגדרה קבועה: הוסיפו ל-~/.bashrc או /etc/profile
echo "umask 027" >> ~/.bashrc
```

## 6. Access Control Lists (ACL) - הרשאות מתקדמות

כאשר rwx בסיסי לא מספיק, ACL מאפשר הרשאות פר-משתמש נוספות.

```bash
# הענקת הרשאת קריאה-כתיבה למשתמש ספציפי
setfacl -m u:john:rw file.txt

# הענקת הרשאות לקבוצה ספציפית
setfacl -m g:developers:rwx /shared/project

# צפייה ב-ACL הקיימות
getfacl file.txt

# הסרת כל ה-ACL
setfacl -b file.txt
```

---

## טיפים וטריקים 🔥

1. **לעולם אל תשתמשו ב-`chmod 777`** בסביבת production - זו פירצת אבטחה חמורה.
2. הרשאה נכונה לתיקיית `.ssh`: `700` לתיקייה, `600` למפתח פרטי, `644` למפתח ציבורי.
3. השתמשו ב-`chmod -R` בזהירות - שקלו `find` עם `-type f`/`-type d` להבדיל בין קבצים לתיקיות:
   ```bash
   find /path -type f -exec chmod 644 {} \;
   find /path -type d -exec chmod 755 {} \;
   ```
4. בדקו הרשאות effective עם `stat file.txt` לקבלת מידע מפורט.
5. שרתי web (Nginx/Apache) בד"כ רצים כ-`www-data` - ודאו ש-chown תואם.

## שאלות ראיון עבודה נפוצות

1. **מה ההבדל בין chmod 755 ל-644?**
   755 (rwxr-xr-x) מתאים לתיקיות וסקריפטים שצריכים הרשאת הרצה. 644 (rw-r--r--) מתאים לקבצים רגילים ללא צורך בהרצה.

2. **מה זה SUID ולמה זה מסוכן?**
   SUID גורם לתוכנית לרוץ בהרשאות הבעלים שלה. זה מסוכן כי אם קובץ עם SUID על root פגיע, תוקף יכול לקבל הרשאות root.

3. **מהי umask ואיך היא משפיעה על קבצים חדשים?**
   umask מגדירה אילו הרשאות מוסרות אוטומטית מברירת המחדל (666 לקבצים, 777 לתיקיות) בעת יצירתם.

4. **איך תיתנו למשתמש ספציפי גישה לקובץ בלי לשנות את בעליו?**
   באמצעות ACL: `setfacl -m u:username:rw file.txt`

5. **מה ההבדל בין chown ל-chgrp?**
   `chown` יכול לשנות גם בעלים וגם קבוצה, `chgrp` משנה רק את הקבוצה.

6. **מה קורה אם למשתמש רגיל אין הרשאת execute על תיקייה?**
   הוא לא יכול "להיכנס" לתיקייה (`cd`) או לגשת לקבצים בתוכה, גם אם יש לו הרשאת read.
