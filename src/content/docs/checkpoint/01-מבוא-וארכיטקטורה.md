## מה זה Check Point?

Check Point Software Technologies היא חברת אבטחת מידע ישראלית (נוסדה ב-1993 על ידי גיל שוויד, מריוס נכט ושלמה קרמר), שהמציאה בין השאר את הקונספט של **Stateful Inspection** - טכנולוגיית הליבה שעליה מבוססים רוב ה-Firewall-ים המודרניים. כיום Check Point מספקת פתרונות אבטחה מקיפים תחת מותג **Infinity**, הכוללים:

- **Quantum** - אבטחת רשת (Firewalls, Gateways)
- **CloudGuard** - אבטחת ענן
- **Harmony** - אבטחת Endpoint, Email, Mobile, SASE
- **Infinity Portal** - ניהול מבוסס ענן (Cloud-based Management)

## ארכיטקטורת שלוש השכבות (Three-Tier Architecture)

זהו הרעיון המרכזי שחייבים להבין לפני כל דבר אחר:

```
┌─────────────────┐        ┌──────────────────────┐        ┌─────────────────┐
│  SmartConsole    │ <----> │ Security Management   │ <----> │ Security Gateway │
│  (GUI Client)     │        │ Server (SMS)          │        │ (Firewall Enforcement)│
└─────────────────┘        └──────────────────────┘        └─────────────────┘
```

1. **SmartConsole** - תוכנת ניהול (GUI, מותקנת על Windows/Cloud) דרכה מנהל המערכת בונה מדיניות, מגדיר אובייקטים, צופה בלוגים.
2. **Security Management Server (SMS)** - "המוח" של המערכת. שומר את מסד הנתונים (Database), את המדיניות, את הלוגים, ומבצע Compile ו-Install Policy לגייטווי.
3. **Security Gateway** - השרת שבפועל אוכף את המדיניות בתעבורת הרשת - מבצע Inspection, NAT, VPN, IPS וכו'.

חשוב להבין: אפשר להתקין את שלושת הרכיבים על אותה מכונה (**Standalone Deployment**), ואפשר לפזר אותם (**Distributed Deployment**) - למשל SMS אחד שמנהל עשרות Gateways בעולם.

## מערכת ההפעלה - Gaia OS

Check Point Gateway ו-Management רצים על מערכת הפעלה ייעודית בשם **Gaia**, המבוססת על ליבת לינוקס. יש לה שתי ממשקים:

- **WebUI** - ממשק ניהול גרפי דרך דפדפן (Portal בכתובת https://<IP>)
- **Gaia CLI (Clish)** - שורת פקודות מובנית, ומעליה גם Expert Mode (Bash) לגישה עמוקה יותר.

מעבר בין המצבים:

```bash
# ב-Clish, מעבר ל-Expert Mode (Bash מלא)
expert

# חזרה מ-Bash ל-Clish
clish
```

## Stateful Inspection - הרעיון המרכזי

בניגוד ל-Packet Filtering הישן (שבודק כל חבילה בנפרד ללא זיכרון), Stateful Inspection שומר **טבלת חיבורים** (Connection Table / State Table) שמנטרת את מצב כל session. כך למשל, אם חיבור HTTP יצא מהרשת הפנימית, החבילה החוזרת (Reply) תותר אוטומטית מבלי שנצטרך לכתוב לה כלל נפרד.

לבדיקת טבלת ה-State בפועל בגייטווי:

```bash
fw tab -t connections -s
```

## רכיבי Software Blades

Check Point בנוי במודל של **Software Blades** - יכולות אבטחה מודולריות שניתן להפעיל או לכבות בנפרד על אותו Gateway:

| Blade | תפקיד |
|---|---|
| Firewall | אכיפת מדיניות בסיסית, Stateful Inspection |
| IPSec VPN | הצפנת תעבורה בין אתרים / למשתמשים מרוחקים |
| IPS | זיהוי ומניעת חדירות (Intrusion Prevention) |
| Application Control | שליטה בגישה לפי אפליקציות (פייסבוק, נטפליקס וכו') |
| URL Filtering | סינון גלישה לפי קטגוריות אתרים |
| Anti-Bot / Anti-Virus | זיהוי תוכנות זדוניות ותקשורת עם שרתי C&C |
| Threat Emulation/Extraction | Sandbox לקבצים חשודים (Sandboxing) |
| Identity Awareness | קישור תעבורה למשתמש/קבוצת AD ולא רק IP |
| Mobile Access | גישה מאובטחת ממכשירים ניידים |
| QoS | ניהול רוחב פס ותעדוף תעבורה |

## דוגמה מעשית: תרשים פריסה בסיסי (Standalone Lab)

```
Internet
   |
[eth0 - External]
   |
+--------------------+
|  Check Point CP    |
|  Standalone (Gaia)  |
|  SMS + Gateway      |
+--------------------+
   |
[eth1 - Internal]  --> 192.168.1.0/24 (LAN)
```

זו הפריסה הכי נפוצה במעבדות לימוד ו-CCSA: מכונה וירטואלית אחת עם שני ממשקים, SIC (Secure Internal Communication) מוגדר בין ה-SMS ל-Gateway (אפילו כשהם על אותה מכונה, יש ערוץ SIC פנימי).

## Secure Internal Communication (SIC)

SIC הוא פרוטוקול תקשורת מוצפן (מבוסס SSL, אימות דו-כיווני עם תעודות) בין SMS ל-Gateway. בלי SIC תקין, ה-Management לא יכול לדחוף מדיניות (Install Policy) לגייטווי. שגיאות SIC הן אחת הבעיות הנפוצות ביותר בתחילת הדרך.

```bash
# בדיקת סטטוס SIC דרך CLI בגייטווי
cpconfig
# ואז לבחור באפשרות SIC / Secure Internal Communication
```

## טיפים וטריקים

- **לפני שמתחילים** - תמיד תבדקו רישוי (License) עם `cplic print` - הרבה תקלות "מוזרות" הן בעצם בעיית רישוי שפג תוקף.
- אל תתבלבלו בין **Policy Install** (דחיפת מדיניות מה-SMS ל-Gateway) ל-**Policy Verify** (בדיקת תקינות בלבד ללא התקנה).
- כדאי להכיר את הפקודה `cpstat` שנותנת תמונת מצב מהירה של כל ה-Blades שרצים.

```bash
cpstat os -f all
cpstat fw
```
