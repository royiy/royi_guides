## איך בנוי ראיון עבודה טיפוסי ל-Check Point Engineer/Administrator

בדרך כלל ראיון כזה כולל 3 שכבות:

1. **שאלות תיאורטיות** - הבנת ארכיטקטורה, מושגי יסוד.
2. **שאלות תרחיש (Scenario-Based)** - "משתמש מתלונן ש-X, איך אתה ניגש לפתור?"
3. **שאלות פרקטיות/CLI** - הכרת פקודות, ולעיתים אפילו משימה חיה על מעבדה (Lab).

## שאלות ארכיטקטורה ויסודות

1. מהי ארכיטקטורת שלוש השכבות של Check Point ומה תפקיד כל רכיב?
2. מהו SIC ואיך הוא עובד?
3. הסבירו את מושג ה-Stateful Inspection.
4. מה ההבדל בין Standalone ל-Distributed Deployment?
5. מהם Software Blades ותנו דוגמאות.
6. מה ההבדל בין Gaia Clish ל-Expert Mode?

## שאלות מדיניות אבטחה ו-NAT

1. מה ההבדל בין Drop ל-Reject?
2. מהו Cleanup Rule ולמה הוא תמיד אחרון?
3. הסבירו את ההבדל בין Hide NAT ל-Static NAT.
4. מה קורה אם כלל רחב יותר נמצא מעל כלל ספציפי ב-Rule Base?
5. מה זה Stealth Rule?
6. מהם Implied Rules?

## שאלות VPN

1. מה ההבדל בין Phase 1 ל-Phase 2 ב-IKE?
2. מה זה VPN Domain?
3. הסבירו Meshed לעומת Star Community.
4. מה ההבדל בין Domain-Based ל-Route-Based VPN?
5. איך הייתם מתחילים לאבחן תקלת VPN?

## שאלות Identity Awareness

1. מה ההבדל בין AD Query ל-Identity Agent?
2. מהו Access Role?
3. איך פותרים מצב שבו AD Query לא מזהה משתמשים?

## שאלות Threat Prevention

1. מה ההבדל בין IPS ל-Anti-Bot?
2. הסבירו Threat Emulation מול Threat Extraction.
3. מה זה ThreatCloud?

## שאלות ניטור ולוגים

1. מה ההבדל בין SmartLog ל-SmartEvent?
2. מה מציגה `fw ctl pstat`?
3. איך הייתם מאתרים למה חבילה נחסמה?

## שאלות Clustering

1. מה ההבדל בין HA Mode ל-Load Sharing Mode?
2. מה תפקיד ה-Sync Interface?
3. איך מבצעים תחזוקה על קלאסטר בלי השבתה?

## שאלות Troubleshooting מתקדמות (לתפקידים בכירים)

1. הסבירו איך עובד `fw monitor` ומה ההבדל בין נקודות i/I/o/O.
2. מה זה CoreXL ואיך בודקים חלוקת עומס בין ליבות?
3. מה חשוב לאסוף לפני פתיחת קייס ל-TAC?
4. תארו תקלה מורכבת שפתרתם (או הייתם פותרים) ואיך ניגשתם אליה.

## "שאלת מלכודת" קלאסית - תרגלו אותה!

**שאלה:** "יש לי כלל ב-Rule Base שאומר Accept מ-Any ל-Server X בפורט 443, אבל המשתמשים עדיין לא מצליחים לגשת. מה יכול להיות הבעיה?"

**תשובה טובה תכלול כמה כיוונים אפשריים**, לא רק אחד:
- ייתכן שיש כלל **מעל** אותו כלל שכבר תופס את התעבורה (Drop).
- בעיית **NAT** - אולי כתובת ה-Destination המקורית לא תואמת בגלל Static NAT שלא הוגדר נכון.
- בעיית **Routing** - התעבורה בכלל לא מגיעה לגייטווי.
- **Threat Prevention** עשוי לחסום למרות שה-Firewall Rule מאשר (Blade נפרד!).
- בעיה ברמת ה-Server עצמו (לא Check Point בכלל).

זו שאלה שבודקת אם אתם חושבים בצורה שיטתית (Layered Thinking) ולא קופצים למסקנות.

## טיפים כלליים להצלחה בראיון

- **דברו בקול רם את תהליך החשיבה** - מראיינים רוצים לראות איך אתם ניגשים לבעיה, לא רק את התשובה הסופית.
- **אל תפחדו להגיד "לא יודע, אבל הנה איך הייתי בודק"** - זה תמיד עדיף על ניחוש שגוי בביטחון.
- הכירו את ההבדל בין **Firewall Layer, Application Layer, ו-Threat Prevention Layer** - שאלה נפוצה שבודקת הבנה אדריכלית.
- אם מדובר בתפקיד עם דגש על Automation - הכירו בסיס על **Check Point API** (Management API - `mgmt_cli`) לניהול תצורה דרך סקריפטים.

```bash
# דוגמה לפקודת Management API בסיסית
mgmt_cli login -u admin -p <password> --format json
mgmt_cli show-hosts --format json
```

- הכינו **סיפור STAR** (Situation, Task, Action, Result) לפחות לתקלה מורכבת אחת שפתרתם - שאלות התנהגותיות ("ספר לי על תקלה שפתרת") נפוצות מאוד גם בתפקידים טכניים.

## רמות הסמכה (Certifications) שכדאי להכיר

| הסמכה | תיאור |
|---|---|
| **CCSA** | Security Administrator - רמת בסיס, ניהול יומיומי |
| **CCSE** | Security Expert - רמה מתקדמת, Troubleshooting, VPN, Cluster |
| **CCSM** | Security Master - רמת מומחה, אחרי CCSE + Specializations |
| **CCSM Elite** | הרמה הגבוהה ביותר |

מומלץ מאוד להזכיר בראיון אם יש לכם הסמכה פעילה, או תוכנית לרכוש אחת - זה מראה רצינות מקצועית.

## טיפים וטריקים כלליים לעבודה יומיומית (לא רק לראיון)

- תמיד לתעד שינויים במדיניות (Change Management) - Check Point תומך ב-**Session Management** שמאפשר לראות מי שינה מה ומתי.
- לפני שינוי גדול, השתמשו ב-**Publish/Discard** של Session במקום לעבוד ישירות על ה-Policy החי.
- גבו קונפיגורציה באופן קבוע (`migrate export` על ה-SMS).
- הכירו את ה-**Check Point CheckMates Community** - מקור עצום לפתרון בעיות אמיתיות מהשטח, כולל תשובות מעובדי Check Point עצמם.

```bash
# גיבוי מלא של ה-Management Database
migrate export -v R81.20 /var/log/backup_export.tgz
```
