## מה זו בינה מלאכותית?

בינה מלאכותית (Artificial Intelligence, בקיצור AI) היא תחום במדעי המחשב שעוסק בבניית מערכות שמסוגלות לבצע משימות שבדרך כלל דורשות "אינטליגנציה" אנושית — הבנת שפה, זיהוי תמונות, קבלת החלטות, פתרון בעיות ולמידה מניסיון.

חשוב להבין: AI הוא מטריה רחבה. בתוכה יש כמה תתי-תחומים מרכזיים:

- **Machine Learning (ML)** — למידת מכונה: מערכות שלומדות דפוסים מנתונים במקום להיות מתוכנתות באופן מפורש לכל תרחיש.
- **Deep Learning (DL)** — למידה עמוקה: תת-תחום של ML המבוסס על רשתות נוירונים מלאכותיות בעלות שכבות רבות.
- **Natural Language Processing (NLP)** — עיבוד שפה טבעית: הבנה, ניתוח ויצירה של שפה אנושית.
- **Computer Vision** — ראייה ממוחשבת: היכולת של המכונה "לראות" ולהבין תמונות, וידאו ומרחב.
- **Reinforcement Learning (RL)** — למידת חיזוק: מערכות (סוכנים) שלומדות לבצע פעולות בסביבה מסוימת באמצעות ניסוי, טעייה ומערכת של תגמולים (Rewards).

## ציר זמן קצר

1. **שנות ה-50**: אלן טיורינג מציע את "מבחן טיורינג". המונח "Artificial Intelligence" נטבע רשמית בכנס דארטמות' ב-1956.
2. **שנות ה-80-90**: פריחה של מערכות מבוססות-כללים (Expert Systems), לצד תקופות של "חורף ה-AI" (הראשון והשני) עקב ציפיות מוגזמות שלא התממשו ומחסור בכוח חישוב.
3. **2012**: פריצת הדרך של AlexNet בתחרות ImageNet — תחילת עידן הלמידה העמוקה המודרנית בזכות שימוש במעבדים גרפיים (GPUs).
4. **2017**: מאמר "Attention Is All You Need" של חוקרי גוגל מציג את ארכיטקטורת ה-**Transformer**, שהפכה לבסיס לכל מודלי השפה הגדולים (LLM) של ימינו.
5. **2020-2022**: מודלי GPT-3, ולאחריו השקת ChatGPT (נובמבר 2022) — ה-AI היוצר (Generative AI) הופך לנגיש להמונים ומשנה את התעשייה.
6. **2023-2026**: עידן ה-Agentic AI (סוכנים אוטונומיים), שילוב טכנולוגיות כמו **RAG** (Retrieval-Augmented Generation) המאפשרות למודלים לשאוב ידע חיצוני מהימן, מולטי-מודליות מלאה (עיבוד סימולטני של טקסט, תמונה, קול ווידאו), ומודלים בעלי יכולות הסקה (Reasoning) מתקדמות.

## איך מכונה "לומדת"?

בגישת ה-ML הקלאסית, אנחנו מזינים למודל דוגמאות (Training Data) עם התשובות הנכונות (Labels). המודל "מתאמן" — כלומר מבצע חישובים ומשנה פרמטרים פנימיים הנקראים **משקלים והטיות (Weights and Biases)** — כך שיוכל לצמצם את רמת השגיאה שלו ולחזות תשובות נכונות גם עבור נתונים חדשים שמעולם לא ראה.

### דוגמה פשוטה בפייתון — רגרסיה לינארית עם scikit-learn

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# נתוני אימון: שטח דירה (מ"ר) מול מחיר (אלפי ש"ח)
X = np.array([[50], [70], [90], [110], [130]])
y = np.array([800, 1100, 1400, 1700, 2000])

model = LinearRegression()
model.fit(X, y)

# חיזוי מחיר לדירה של 100 מ"ר
prediction = model.predict([[100]])
print(f"מחיר משוער: {prediction[0]:.0f} אלף ש\"ח")
```

### דוגמה — רשת נוירונים פשוטה עם PyTorch

```python
import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(10, 32)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(32, 1)

    def forward(self, x):
        x = self.relu(self.layer1(x))
        return self.layer2(x)

model = SimpleNet()
x = torch.randn(5, 10)  # 5 דוגמאות (Batch), שלכל אחת מהן 10 מאפיינים (Features)
output = model(x)

# הפלט יהיה טנזור בגודל [5, 1] המייצג את החיזוי עבור 5 הדוגמאות
print(output)
```

## מושגי יסוד שכדאי להכיר

| מושג | הסבר קצר |
| ---: | ---: |
| **Supervised Learning** | למידה מודרכת — המודל לומד מתוך נתונים שיש להם תוויות (Labels) מוגדרות מראש. |
| **Unsupervised Learning** | למידה ללא פיקוח — מציאת דפוסים וקבוצות במידע ללא תוויות (למשל, Clustering). |
| **Reinforcement Learning** | למידה מחיזוקים — סוכן הלומד לפעול בסביבה כדי למקסם "פרס" או משוב חיובי. |
| **Overfitting** | "התאמת יתר": המודל "שינן" את נתוני האימון ולא מסוגל להכליל ולעבוד נכון על נתונים חדשים. |
| **Epoch** | מחזור אימון שלם שבו המודל נחשף פעם אחת לכל נתוני האימון. |
| **Batch Size** | כמות הדוגמאות שהמודל מעבד במקביל בכל פעם, לפני שהוא מעדכן את המשקלים שלו. |
| **Neural Network** | רשת נוירונים מלאכותית — מודל מתמטי הבנוי משכבות ומקשרים, בהשראת מבנה המוח. |
| **Gradient Descent** | אלגוריתם אופטימיזציה שבעזרתו המודל מוצא את המשקלים הטובים ביותר למזעור השגיאה. |
| **Backpropagation** | התהליך בו רשת הנוירונים מחשבת את הטעות שלה ומעדכנת את המשקלים אחורה (מהפלט לקלט). |

## שאלות נפוצות (בסיס AI/ML)

1. **מה ההבדל בין AI, Machine Learning ו-Deep Learning?**

   AI הוא התחום הרחב של יצירת מכונות חכמות, ML הוא תת-תחום שמתמקד באלגוריתמים הלומדים מנתונים, ו-DL הוא תת-תחום של ML שמבוסס באופן ספציפי על רשתות נוירונים עמוקות.
2. **מהו Overfitting וכיצד מתמודדים איתו?**

    מצב שבו המודל לומד "בעל פה" את נתוני האימון (כולל את הרעש שבהם) ונכשל על נתונים חדשים. פתרונות נפוצים: Regularization (L1/L2), טכניקת Dropout, הגדלת מאגר הנתונים (Data Augmentation), Cross-Validation, ו-Early Stopping.
3. **הסבירו את ה-Bias-Variance Tradeoff.**

    Bias גבוה אומר שהמודל פשוט מדי ולא מצליח ללכוד את התבנית בנתונים (Underfitting). Variance גבוה אומר שהמודל רגיש מדי לשינויים בנתוני האימון ולכן לא מכליל טוב (Overfitting). המטרה באימון מודל היא למצוא את נקודת האיזון ביניהם (ה-Tradeoff).
4. **מה ההבדל בין Supervised ל-Unsupervised Learning? תנו דוגמה לכל אחד.**

   ב-Supervised Learning המודל מקבל נתונים מתויגים עם תשובה נכונה (למשל: סיווג תמונות ל"כלב" או "חתול"). ב-Unsupervised Learning המודל מקבל נתונים גולמיים ללא תוויות, ועליו למצוא בהם חוקיות בעצמו (למשל: חלוקת לקוחות לקבוצות התנהגות שונות - Clustering).
5. **מהי פונקציית Loss (פונקציית הפסד) ולמה היא חשובה?**

    פונקציית ה-Loss מחשבת את גודל הפער בין התחזית של המודל לבין התשובה הנכונה בפועל. היא חשובה מכיוון שהיא מספקת למודל את ה"ציון" על פיו הוא מתקן את הטעויות שלו — כל תהליך האימון מטרתו היא למזער את ה-Loss ככל הניתן.

## טיפים וטריקים למתחילים

- **התחילו מפרויקט קטן ומוחשי** — למשל, בניית מודל לחיזוי מחירי דירות (ML קלאסי), לפני שקופצים ל-Deep Learning מורכב.
- **הבינו את המתמטיקה ברמה הבסיסית** — אלגברה לינארית, נגזרות, והסתברות יעזרו לכם להבין *איך* המודלים עובדים ולא רק להריץ אותם כ"קופסה שחורה".
- **קראו קוד של אחרים** — עברו על פתרונות ופרויקטים ב-Kaggle וב-GitHub לפני שאתם כותבים מאפס.
- **אל תבנו מודל מאפס אם לא חייבים** — כמעט תמיד יש מודל Pretrained רלוונטי ב-Hugging Face שאפשר לקחת ולעשות לו Fine-tuning.
- **שימו לב ל-Data Quality** — הכלל "Garbage in, garbage out" נכון תמיד. איכות וניקיון הנתונים חשובים לא פחות (ולעיתים יותר) מארכיטקטורת המודל או מכמות הפרמטרים שלו.
