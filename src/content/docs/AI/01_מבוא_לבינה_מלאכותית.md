## מה זו בינה מלאכותית?

בינה מלאכותית (Artificial Intelligence, בקיצור AI) היא תחום במדעי המחשב שעוסק בבניית מערכות שמסוגלות לבצע משימות שבדרך כלל דורשות "אינטליגנציה" אנושית — הבנת שפה, זיהוי תמונות, קבלת החלטות, פתרון בעיות ולמידה מניסיון.

חשוב להבין: AI הוא מטריה רחבה. בתוכה יש כמה תתי-תחומים מרכזיים:

- **Machine Learning (ML)** — למידת מכונה: מערכות שלומדות דפוסים מנתונים במקום להיות מתוכנתות באופן מפורש לכל מקרה.
- **Deep Learning (DL)** — למידה עמוקה: תת-תחום של ML המבוסס על רשתות נוירונים עם שכבות רבות.
- **Natural Language Processing (NLP)** — עיבוד שפה טבעית: הבנה ויצירה של טקסט אנושי.
- **Computer Vision** — ראייה ממוחשבת: הבנת תמונות ווידאו.
- **Reinforcement Learning (RL)** — למידת חיזוק: מערכות שלומדות באמצעות ניסוי, טעייה ותגמול.

## ציר זמן קצר

1. **שנות ה-50**: אלן טיורינג מציע את "מבחן טיורינג". המונח "Artificial Intelligence" נטבע בכנס דארטמות' ב-1956.
2. **שנות ה-80-90**: מערכות מבוססות כללים (Expert Systems), "חורף ה-AI" הראשון והשני עקב ציפיות מוגזמות.
3. **2012**: פריצת הדרך של AlexNet בתחרות ImageNet — תחילת עידן הלמידה העמוקה המודרנית.
4. **2017**: מאמר "Attention Is All You Need" של גוגל מציג את ארכיטקטורת ה-**Transformer**, שהיא הבסיס לכל מודלי השפה הגדולים (LLM) של היום.
5. **2020-2022**: מודלי GPT-3, ואז ChatGPT (נובמבר 2022) — AI הופך לנגיש להמונים.
6. **2023-2026**: עידן ה-Agentic AI, ה-MCP, מולטי-מודליות (טקסט+תמונה+קול+וידאו), ומודלים בעלי יכולות הסקה (reasoning) מתקדמות.

## איך מכונה "לומדת"?

בגישת ML הקלאסית, אנחנו מזינים למודל דוגמאות (Training Data) עם תשובות נכונות (Labels), והמודל "מתאמן" — כלומר משנה פרמטרים פנימיים (משקלים) כך שיוכל לחזות תשובות נכונות גם על נתונים חדשים שלא ראה.

### דוגמה פשוטה בפייתון — רגרסיה לינארית עם scikit-learn

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# נתוני אימון: שטח דירה (מ"ר) מול מחיר (אלפי ש"ח)
X = np.array([[50], [70], [90], [110], [130]])
y = np.array([800, 1100, 1400, 1700, 2000])

model = LinearRegression()
model.fit(X, y)

# חיזוי מחיר לדירה של 100 מ"ר
prediction = model.predict([[100]])
print(f"מחיר משוער: {prediction[0]:.0f} אלף ש\"ח")
```

### דוגמה — רשת נוירונים פשוטה עם PyTorch

```python
import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(10, 32)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(32, 1)

    def forward(self, x):
        x = self.relu(self.layer1(x))
        return self.layer2(x)

model = SimpleNet()
x = torch.randn(5, 10)  # 5 דוגמאות, 10 features כל אחת
output = model(x)
print(output)
```

## מושגי יסוד שכדאי להכיר

| מושג | הסבר קצר |
|---|---|
| Supervised Learning | למידה מודרכת — יש תוויות (labels) לכל דוגמה |
| Unsupervised Learning | למידה ללא פיקוח — מציאת דפוסים ללא תוויות (לדוגמה clustering) |
| Reinforcement Learning | למידה מתגמול — סוכן לומד ממשוב סביבתי |
| Overfitting | המודל "שינן" את נתוני האימון ולא מכליל טוב לנתונים חדשים |
| Neural Network | רשת נוירונים מלאכותית — מודל בהשראת המוח |
| Gradient Descent | אלגוריתם אופטימיזציה למציאת המשקלים הטובים ביותר ברשת |
| Backpropagation | תהליך חישוב הגרדיאנטים בעזרתו הרשת "לומדת" מטעויות |

## שאלות ראיון עבודה נפוצות (בסיס AI/ML)

1. **מה ההבדל בין AI, Machine Learning ו-Deep Learning?**
   תשובה מצופה: AI הוא התחום הרחב, ML הוא תת-תחום שמתמקד בלמידה מנתונים, ו-DL הוא תת-תחום של ML שמבוסס על רשתות נוירונים עמוקות.

2. **מהו Overfitting וכיצד מתמודדים איתו?**
   תשובה: המודל לומד "בעל פה" את נתוני האימון כולל רעש. פתרונות: Regularization (L1/L2), Dropout, הגדלת דאטה, Cross-Validation, Early Stopping.

3. **הסבירו את ה-Bias-Variance Tradeoff.**
   תשובה: Bias גבוה = המודל פשוט מדי ולא לוכד את התבנית (underfitting). Variance גבוה = המודל רגיש מדי לנתוני האימון (overfitting). המטרה היא איזון.
