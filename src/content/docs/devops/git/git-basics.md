## מה זה Git?

Git הוא מערכת לניהול גרסאות - "היסטוריית שינויים" חכמה לפרויקט. כל פעם שאתה מרוצה משלב מסוים בעבודה, אתה שומר "תמונת מצב" (commit), ו-Git זוכר בדיוק מה השתנה, מתי, ומי עשה את זה. זה מאפשר לחזור אחורה, להשוות בין גרסאות, ולעבוד בבטחה גם אם משהו נשבר.

**GitHub** הוא שירות אונליין שמאחסן את ההיסטוריה הזו בענן - לגיבוי, לגישה מכל מחשב, ולחיבור לשירותי אירוח שמפרסמים אתרים אוטומטית.

## דרישות מוקדמות

- Git מותקן על המחשב ([git-scm.com](https://git-scm.com))
- חשבון GitHub
- פרויקט מקומי שכבר מכיל קבצים

## הגדרה חד-פעמית

לפני ה-commit הראשון אי פעם על מחשב חדש, צריך לומר ל-Git מי אתה:

```
git config --global user.email "your@email.com"
git config --global user.name "Your Name"
```

הפעולה הזו נדרשת פעם אחת בלבד למחשב, ולא צריך לחזור עליה בכל פרויקט.

## הפקודות שלב אחר שלב

### 1. `git add .`

מסמן שקבצים ששינית (או חדשים) עומדים לשמירה בשלב הבא.

### 2. `git commit -m "תיאור"`

שומר בפועל את תמונת המצב שסומנה ב-`add`, יחד עם הודעה שמתארת מה השתנה.

### 3. `git branch -M main`

משנה את שם הענף (branch) הראשי ל-`main`.

### 4. `git remote add origin <כתובת>`

מחבר את הפרויקט המקומי לכתובת הריפו ב-GitHub, וקורא לחיבור הזה "origin".

### 5. `git push -u origin main`

מעלה בפועל את ה-commits המקומיים לענף `main` שב-GitHub.

## תהליך העבודה השוטף

אחרי שהחיבור הראשוני מוגדר, כל פעם שמשנים משהו בפרויקט מספיקות שלוש פקודות:

```
git add .
git commit -m "תיאור קצר של מה ששיניתי"
git push
```

## סיכום

Git עובד במחזור פשוט: משנים קבצים → `git add` מסמן אותם → `git commit` שומר תמונת מצב מקומית → `git push` מעלה אותה ל-GitHub.
